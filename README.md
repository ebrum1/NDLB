# No Dog Left Behind – the coverage cube

An interactive teaching visual for dog-rabies elimination programme design.  Vaccination coverage is three-dimensional – spatial uniformity, speed and synchrony, and reach into the free-roaming population.  Reach is the weakest of the three axes, and the vaccine's efficacy and duration multiply it.  The cube never changes size; only the ball moves.

Pages:

- `index.html` – the looping eight-scene animation.  Drag to spin the cube, double-click to reset the view; SPACE pauses, arrow keys step, R restarts, F goes full screen.
- `cube.html` – the hands-on version.  Drag the four sliders, spin the cube, and watch the ball and the glow respond.

Both pages are single self-contained HTML files with no external dependencies, and also work offline from a local copy.

*A teaching heuristic, not a model of elimination probability.*
